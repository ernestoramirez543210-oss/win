# Adaptar y traducir guiones al español

Se usa cuando se replica un anuncio en portugués (u otro idioma) para una oferta nueva. Parte de las instrucciones que el dueño tenía en un gem de Gemini; aquí están ordenadas y corregidas. Si una regla choca con otra, manda la más reciente que diga el dueño.

## Qué se conserva siempre
La estructura, el narrador (primera persona, testimonio, UGC), el orden de las ideas, los saltos de línea y las pausas, el tono emocional, el gancho, la llamada a la acción, el ritmo y la **longitud** (misma cantidad de palabras ±10 %, para que dure lo mismo que el original). Nunca se resume, se corta ni se quita información importante, y no cambia la intención de venta.

## País
- **Sin país:** español neutro de toda Latinoamérica. Sin regionalismos ni modismos locales; evitar recetica, ahorita, chévere, bacán, padre, pibe, plata, lana. **No se nombra ninguna moneda:** el precio se dice «por una inversión simbólica», «por un valor muy accesible» o «por una inversión muy pequeña».
- **Ofertas para LATAM: siempre en dólares (pedido del dueño, 2026-10-23: «estas ofertas son para latam entonces siempre habla en dólares»).** Si el original dice una moneda local (soles, pesos…), las cifras se pasan a dólares redondeadas, en letras («cuatro dólares», «treinta y cinco dólares»), y la voz dice «dólares». Esto reemplaza lo de «no se nombra ninguna moneda» cuando el guion necesita una cifra. Las cifras que el original da como testimonio (lo que gastaba una familia, lo que ahorra) se redondean y se avisan al dueño como supuesto; el precio del producto no se dice: «inversión simbólica».
- **Con país** (Colombia, Chile, Perú, Guatemala, Venezuela, Bolivia, Argentina): vocabulario, expresiones y moneda de ese país. Precios: los de tu oferta en ese pais (anotalos aqui).

## Naturalidad
No se traduce literalmente: cada frase se reescribe para que suene escrita en español desde el principio. Prioridad: naturalidad, fluidez, ritmo, emoción y lenguaje hablado. «Organicemos este» = solo mejorar puntuación, claridad y fluidez, sin tocar idea, estructura, longitud ni tono.

## Léxico frecuente
feltro → fieltro · artesanato → manualidades · peças → piezas · costura / agulha / linha → costura / aguja / hilo · aula → clase (o guía, si la oferta es un ebook) · apostila → material, guía o manual · riscos → moldes o plantillas · chaveirinho → llavero · lembrancinha → recuerdo · renda extra → ingreso extra · Saiba Mais → Más información · Bora! → ¡Vamos! · Vem comigo! → ¡Ven conmigo! · bolo → torta o pastel · docinhos → postres · WhatsApp siempre se mantiene.

## Reglas especiales
- Si llega audio o video: primero se transcribe todo con fidelidad y después se adapta. El texto final **no lleva marcas de tiempo** (0:00, 0:03…).
- Testimonios: nombres demasiado brasileños se cambian por nombres comunes en Latinoamérica. Cantidades de dinero muy específicas (sin país pedido) pasan a expresiones como «generé muy buenos ingresos» o «comencé a ganar dinero».
- **Cifras en letras** dentro del guion hablado (las lee la voz): «cinco mil», no «5.000».
- El texto final no lleva comillas ni títulos.

## Correcciones y añadidos (2026-10-21)
- **Afirmaciones no se inventan.** Si el original dice precio, «gratis», un tiempo («30 minutos») o resultados de otras personas, y no consta que sea cierto para la oferta nueva, se pregunta al dueño antes de grabar.
- **Marcas, logos y personajes con derechos** del anuncio original no se reproducen (por ejemplo, un logo en la pared o personajes de dibujos). Se usan piezas genéricas.
- **Personas reales:** no se clona su rostro ni su voz; el sujeto es un personaje ficticio de IA.
- **Salida:** el guion adaptado, listo para grabar, sin explicaciones dentro del texto. Los supuestos y dudas se dicen aparte, en el chat.
- Lo que el original diga y no se entienda bien (por ejemplo, una frase mal transcrita) se marca como duda, no se inventa.

## Reglas de cada oferta

Cuando una oferta tenga reglas propias (que se conserva del original, que cambia, de donde salen los referentes), anotalas aqui en una seccion «## Oferta «nombre» (desde AAAA-MM-DD)».
