# Preferencias del editor (correcciones anotadas)

Claude lee este archivo ANTES de editar cualquier anuncio y lo aplica sin que se lo recuerden.
Cada vez que el dueño corrija algo de una edición, se anota aquí con la fecha y el motivo.

Formato de cada entrada (la más reciente arriba):

```
## AAAA-MM-DD · anuncio · tema corto
- Corrección: qué pidió cambiar, en sus palabras.
- Motivo: por qué (si no lo dijo, se pregunta).
- Regla derivada: cómo se aplica de ahora en adelante.
```

Si una corrección es para siempre, además se pasa a CLAUDE.md o a la skill.

## Reglas de partida

- **Música:** solo música propia (la que crea `scripts/crear_musica.py`) o con licencia clara para anuncios pagados. Ante la duda sobre una canción, se pregunta antes de usarla: una canción comercial en un anuncio puede hacer que Meta lo rechace o que llegue un reclamo de derechos.

(Todavía no hay correcciones anotadas.)
